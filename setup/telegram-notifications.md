# ترحيب الطلاب وإشعارات تليجرام

الترحيب لا يطلب أسماء الزوار حتى تفعيل TELEGRAM_BOT_TOKEN وTELEGRAM_CHAT_ID على Vercel. عند عدم تفعيل الخدمة يظل الموقع يعمل كما هو. الطالب يمكنه التصفح كزائر دائمًا.

أنشئ بوتًا من BotFather الرسمي باستخدام /newbot، ثم افتح بوتك واضغط Start. احفظ المفتاح في Vercel Environment Variables باسم TELEGRAM_BOT_TOKEN فقط؛ لا تضعه في المحادثة أو GitHub أو JavaScript. TELEGRAM_CHAT_ID هو معرف محادثتك الخاصة مع البوت (رقم موجب)، ويجب التحقق أنه يعود إلى حساب مستر كريم قبل الإرسال. أعد النشر بعد الإعداد.

مشاركة الاسم اختيارية وواضحة في النموذج. لا نطلب كلمة سر أو رقم هاتف أو حساب الطالب على تليجرام. الإشعار يضم الاسم المكتوب والصف والوقت بتوقيت القاهرة ومصدر الرابط أو اختيار الطالب. الاسم ليس إثبات هوية. المصدر قد يكون مجهولًا؛ لا نرسل موقعًا جغرافيًا أو IP أو query string. لا نحتاج قاعدة بيانات إضافية: الرسائل تصل إلى محادثة مستر كريم الخاصة. لوحة الأسماء وإحصاءات الزيارات الكلية تحتاج تخزينًا منفصلًا لاحقًا.

تكرار التحميل لا يعيد الإشعار إذا وصل رد النجاح وحُفظ محليًا. حماية التكرار وحدود السيرفر مؤقتة لكل نسخة تشغيل، وليست عدادًا موزعًا دائمًا. مسح بيانات المتصفح أو جهاز آخر أو مهلة اتصال بعد وصول الرسالة قد ينتج تسجيلًا جديدًا. لا يعاد الإرسال آليًا عند الفشل. مع زيارات كبيرة أو إساءة استخدام يلزم CAPTCHA وتخزين دائم للحدود.

اختبر باسم تجريبي بعد موافقة مستر كريم وتأكد من وصوله لمحادثته الخاصة. GET /api/visitors يعيد enabled:false قبل التفعيل ولا يكشف الأسرار. الإرسال نص عادي دون HTML أو Markdown، ولا تسجل الأسرار في سجلات الأخطاء.

# التغييرات

- إعادة بناء الرئيسية بهوية أسود وذهبي وبوابات بثلاثة ألوان.
- إزالة الاعتماد على Tailwind CDN وThree.js من الواجهة الجديدة، واستبدالهما بـ CSS وSVG وحركات خفيفة.
- خطوط عربية محلية وصور WebP محسنة للواجهة؛ الأصول الأصلية محفوظة.
- توحيد المدخل الجديد إلى index.html، وحفظ نسختي الرئيسية الأصليتين للمقارنة.
- تصحيح رابط geography_map.pptx إلى geography_map.pdf.
- 35 ملف تعلم للترم الأول، و140 سؤالًا أصليًا مع تفسير.
- أدوات تفاعلية متكاملة لثلاثة صفوف: بطاقات وخريطة وخزنة وخط زمني وسيناريوهات قرارات واختبارات.
- تقدم ومراجعة أخطاء وتصدير واستعادة محلي، ومزامنة Supabase اختيارية مع SQL وسياسات عزل.
- أوراق HTML لكل درس و3 ملفات PDF، واستوديو إعداد وتصدير محلي.
- تصميم للموبايل وشريط تنقل سفلي وروابط عميقة لكل درس وأداة.
- الحفاظ على الألعاب الأربع وصور المعرض والفيديو ولوحتي PDF الأصليتين.
- ربط نشاط فيسبوك الفعلي المرفق في نسخة المشروع، وإزالة أزرار السوشيال الفارغة.
- حذف آراء غير موثقة من واجهة العرض الجديدة، وعدم إضافة نتائج أو أعداد طلاب مختلقة.
- تحديث حقوق النشر تلقائيًا، وصفحات تعريف وحجز ومصادر.
- حفظ أساس المنصة دون اتصال على HTTPS، وتحكم في الصوت والحركة.
